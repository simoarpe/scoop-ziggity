# scoop-ziggity

A [Scoop](https://scoop.sh) bucket for [ziggity](https://github.com/simoarpe/ziggity),
a fast terminal UI for Git written in Zig.

## Install

```powershell
scoop bucket add ziggity https://github.com/simoarpe/scoop-ziggity
scoop install ziggity
```

ziggity drives `git` as a subprocess, so you need git on your `PATH`. Either
install [Git for Windows](https://git-scm.com/download/win) or add Scoop's own:

```powershell
scoop install git
```

## Update

```powershell
scoop update ziggity
```

You get whatever version this bucket's manifest currently points at. The bucket
keeps itself current automatically (see below), so this tracks ziggity releases.

## Notes

- Only `x86_64` (64-bit) is published.

## How this bucket stays current

`bucket/ziggity.json` is generated by ziggity's own release workflow. When a new
version is tagged, that workflow renders the manifest (version, download URL, and
the sha256 read from the release's `checksums.txt`) and pushes it here, the same
way it updates the Homebrew tap. So this bucket tracks releases automatically,
with no manual edits.

The manifest template lives in the ziggity repo at
`.github/scoop/ziggity.json.tmpl`; edit it there if the manifest needs to change.
